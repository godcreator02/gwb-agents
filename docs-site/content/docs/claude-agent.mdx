**本页回答**：`plugins/claude-agent` 负责什么、对外给什么、依赖谁，以及刻意不做的事。

## 功能

每一轮调一次 Claude Agent SDK 的 `query()`：新会话用插件自己定的 UUID 当会话号，续聊用 `resume`。SDK 在后台启动它附带的那份 Claude Code（SDK 0.3.N 配 Claude Code 2.1.N），权限 `bypassPermissions`，照常加载本机 `~/.claude` 的设置、CLAUDE.md、MCP 与 hooks。开始了就交回，结果由 SDK 交回的 result 消息记下；跑着的时候记下主代理的工具调用与最近一段回答，给 `status` 当进度。

**模型不写死**：设置里一组 `models`，每份是模型名、请求地址、token。不填请求地址的一份用本机已登录的 Claude，只换模型名；填了的一份是第三方的 Anthropic 兼容接口。一份都不选时用本机 Claude、Claude Code 自己的默认模型。会话建立时用哪份，续聊沿用它。

**SDK 不打包**：SDK 附带的 Claude Code 约 257 MB，打不进插件。用户照说明书 `claude-agent-setup` 用 npm 全局装好，把 `npm ls -g` 交回的包目录填进设置 `sdk-dir`；插件只认这里，版本不在支持范围里就报错：

## 接口

本体是服务 `gwbClaudeAgent`，别的插件 inject 它调方法；`claude-agent.*` 命令给 agent 用，只查参数形状、再调同名方法。类型在本包 `src/api.ts`：

{/* ref file="../plugins/claude-agent/src/api.ts" lines="70-84" hash="03c4b83f49e1" blob="d4cbc50893ea" */}

| 方法 / 命令 | 参数 | 作用 |
| --- | --- | --- |
| `create` / `claude-agent.create` | `{workspace,prompt,model?}` | 新建会话并开始第一轮，返回 `{sessionId,round,model,accepted:true}`，只表示开始了 |
| `send` / `claude-agent.send` | `{workspace,sessionId,prompt,interrupt?}` | 续一轮；上一轮还在跑时不带 `interrupt` 报错，带 `interrupt:true` 先结束它（那一轮记 `failed`）再开 |
| `status` / `claude-agent.status` | `{workspace,sessionId}` | `running` 以外都是这一轮结束了；`completed` 带最终回答，`failed` 带原因；`running` 时带进度 `{toolCalls,lastTool,lastText}` |
| `setupStatus` / `claude-agent.setup-status` | 无 | SDK 装好没有、各份模型配好没有，不含 token 的值 |

续一轮与打断。打断时先按进程树结束 Claude Code（`taskkill /T /F`），再让 SDK 收尾：Windows 上只结束 claude.exe 不会连带结束它用 Shell 工具开的命令，SDK 的 `close()` 等不到它自己退出时正是只结束 claude.exe。为了拿到 pid，Claude Code 由插件经 SDK 的 `spawnClaudeCodeProcess` 自己启动；插件卸载时在跑的一轮也这样结束：

**给 SDK 子进程的环境去掉 Claude Code 的会话变量**：工作台可能由 Claude Code 会话启动，带着桌面版塞进来的变量时子进程改用桌面版的登录、盖掉第三方模型的 token（实验在 `probes/2610152150_third-party-auth/`）。`CLAUDE_*`、`ANTHROPIC_*` 这类名字只传 Windows 用户级、系统级长期环境变量里有的，那是用户自己设的，比如打开 PowerShell 工具的 `CLAUDE_CODE_USE_POWERSHELL_TOOL`，去掉它子会话就没有 Shell 工具；`~/.claude/settings.json` 的 `env` 由 Claude Code 自己读：

## 不做的事

- **不打包 SDK、不自动找 SDK**：只认设置 `sdk-dir`（轨迹卡[「换 Agent SDK」](/trajectory/2026-10-15-claude-agent-sdk)）
- **不做界面**：会话只在 `status` 里看；要人看着做的活交给 ZCode
- **不管占用、不参与回报**：同一个工作区开几条会话由调用方决定；要不要回报、报给谁由派任务的一方写进提示词
- **不自动重发**：出错、被打断、插件重载中断的轮次记 `failed`，由调用方决定要不要再派
