**本页回答**：这个仓里反复出现的词各指什么。

| 词 | 意思 |
| --- | --- |
| ZCode 桌面端 | 本机装的 ZCode 客户端程序（Electron），一个主进程加若干渲染进程与会话进程 |
| 会话 / 任务 | ZCode 侧栏里的一条，id 以 `sess_` 开头；ZCode 内部两个叫法混用，本仓命令参数叫 `task`、回执叫 `taskId` |
| 代理进程 | 每条会话背后跑模型、调工具的进程（`zcode.cjs app-server`）；它实际用的模式记在自己的设置里，可能和界面显示的不一样 |
| 一轮 | 发出一条指令到 ZCode 做完它之间的过程；回执只带这一轮新出现的回答 |
| 完全访问 | ZCode 界面上的一种权限模式，内部值 `yolo`：改文件、运行命令都不先问人 |
| 变更前确认 | ZCode 界面上的另一种权限模式，内部值 `build`：改文件前停下等人确认；新建会话默认是它 |
| 工作区窗口 | ZCode 打开一个工作区目录的那个窗口；插件只认恰好一个的情形 |
| 调试端口 | Node 的调试协议端口 9229，打开后能在 ZCode 主进程里执行脚本 |
| 归档 | 把会话从侧栏的会话列表里收起来，记录不删，ZCode 的已归档列表里还看得到 |
| 侧栏 | ZCode 窗口左边列出会话的那一栏；CLI 无界面跑出来的会话不在这里 |
